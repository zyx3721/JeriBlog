## 📋 版本概述

v3.1.2 版本聚焦于管理后台文章导出的图片下载稳定性。当文章图片链接来自 `raw.githubusercontent.com` 时，导出 ZIP 过程会在下载地址前自动加上 `https://gh-proxy.com/`，提升 GitHub 图床图片的打包成功率。

---

## ✨ 新增特性

- 无新增用户功能。

---

## 🐛 Bug 修复

### 文章导出时 GitHub 图床图片下载失败
- 新增导出专用图片代理常量 `https://gh-proxy.com/`。
- 新增 `resolveExportImageDownloadURL` 辅助逻辑，对 `raw.githubusercontent.com` 图片自动生成代理下载地址。
- 调整 `DownloadZip` 中的图片下载流程，下载时使用解析后的 URL，ZIP 内文章内容替换逻辑保持不变。

---

## 🚀 性能优化

- 仅在图片 URL host 为 `raw.githubusercontent.com` 时才加代理前缀，普通 CDN、本站上传资源和其他图床保持原链下载。

---

## 🔧 重构优化

- 将文章导出 ZIP 的图片代理解析从并发下载逻辑中抽离为独立函数，便于后续复用和测试。
- 复用已有 `isGitHubRawURL` host 判断逻辑，避免使用简单字符串包含判断造成误判。
