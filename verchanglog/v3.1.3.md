# JeriBlog v3.1.3 版本更新日志

**发布日期**: 2026-05-18  
**提交数量**: 2 次提交  
**版本类型**: 功能版本（Feature Release）

---

## 📋 版本概述

v3.1.3 版本围绕评论管理与主题体验展开，新增评论置顶能力，并支持前台主题按配置时间自动切换。管理后台同步补充置顶开关和主题时间配置，后端新增公开配置项与数据库迁移，提升站点互动内容管理效率和昼夜主题体验。

---

## ✨ 新增特性

### 评论置顶功能
- 管理后台评论列表新增置顶开关，可对指定评论切换置顶状态。
- 前台评论展示新增置顶标识，置顶评论在同级评论中优先展示。
- 新增评论置顶管理接口，便于后台统一操作评论排序。

### 主题自动切换功能
- 新增前台客户端主题自动切换插件，根据配置时间自动切换日间/夜间主题。
- 管理后台博客设置新增“日间开始”和“夜间开始”时间配置。
- 系统配置新增默认主题切换时间：日间 `06:00`，夜间 `18:00`。

---

## 🐛 Bug 修复

- 本版本无独立 Bug 修复提交。

---

## 🚀 性能优化

- 主题自动切换使用 `setTimeout` 调度下一次切换点，避免持续轮询。
- 评论排序直接在查询层按 `is_pinned` 与创建时间排序，减少前端二次处理。

---

## 🔧 重构优化

- 评论 DTO、后台类型和前台类型统一补充 `is_pinned` 字段。
- 主题工具模块新增时间解析、当前主题判断和下一次切换时间计算逻辑。
- 博客系统配置加载流程补充主题自动切换配置默认值与数据库覆盖逻辑。

## 🔄 API 变更

### 新增后台接口

```http
PUT /api/v1/admin/comments/{id}/toggle-pinned
```

**说明**: 切换评论置顶状态，置顶评论会在同级评论中排在最前面。

### 响应字段变更

- 评论列表与评论详情响应新增 `is_pinned` 字段，用于标识评论是否置顶。

---

## 📊 数据库变更

### 新增评论字段

```sql
ALTER TABLE comments ADD COLUMN IF NOT EXISTS is_pinned BOOLEAN NOT NULL DEFAULT FALSE;
```

### 新增系统配置项

```sql
INSERT INTO settings (key, value, "group", is_public, created_at, updated_at)
VALUES ('blog.theme_light_start', '06:00', 'blog', TRUE, CURRENT_TIMESTAMP, CURRENT_TIMESTAMP)
ON CONFLICT (key) DO UPDATE SET updated_at = CURRENT_TIMESTAMP;

INSERT INTO settings (key, value, "group", is_public, created_at, updated_at)
VALUES ('blog.theme_dark_start', '18:00', 'blog', TRUE, CURRENT_TIMESTAMP, CURRENT_TIMESTAMP)
ON CONFLICT (key) DO UPDATE SET updated_at = CURRENT_TIMESTAMP;
```
