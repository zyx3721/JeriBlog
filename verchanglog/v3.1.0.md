## 📋 版本概述

v3.1.0 版本专注于**核心功能修复与优化**，解决了移动端侧边栏交互逻辑问题、邮件发送格式处理问题，并更新了第三方 API 地址，提升了系统的稳定性和用户体验。

---

## ✨ 核心变更

### 1. 侧边栏交互逻辑重构
- **优化内容**: 
  - 移除基于 checkbox + label 的传统控制方式
  - 改用 Vue 响应式状态管理（`mobileSidebarVisible`）
  - 添加 `openMobileSidebar` 和 `closeMobileSidebar` 方法
  - 新增路由监听，路由变化时自动关闭移动端侧边栏
  - 优化遮罩层交互逻辑
- **影响范围**: 
  - `admin/src/components/layouts/Header.vue`
  - `admin/src/layouts/AdminLayout.vue`
- **用户体验**: 移动端侧边栏打开/关闭更流畅，路由切换时自动关闭，避免遮挡内容

### 2. 邮件发件人格式处理修复
- **修复内容**: 
  - 检测邮箱地址是否已包含 `<>` 格式
  - 避免重复格式化导致的邮件发送失败
- **影响范围**: `server/pkg/email/client.go`
- **用户体验**: 修复特定邮箱配置下的邮件发送失败问题

### 3. 一言 API 地址更新
- **更新内容**: 
  - 从 `api.pearktrue.cn` 更新到 `api.pearapi.ai`
  - 确保一言功能持续可用
- **影响范围**: `admin/src/views/Dashboard.vue`
- **用户体验**: 仪表盘一言功能恢复正常

## 🐛 Bug 修复

### 移动端侧边栏交互问题
- **问题描述**: 使用 checkbox 控制侧边栏存在状态管理不一致的问题
- **解决方案**: 改用 Vue 响应式状态管理，统一控制逻辑
- **影响**: 移动端用户体验显著提升

### 邮件发送格式错误
- **问题描述**: 当邮箱地址已包含 `<>` 格式时，重复格式化导致发送失败
- **解决方案**: 添加格式检测，避免重复处理
- **影响**: 修复特定邮箱配置下的邮件发送问题

### 一言 API 失效
- **问题描述**: 旧 API 地址不可用
- **解决方案**: 更新到新的 API 地址
- **影响**: 仪表盘一言功能恢复

## 🔧 技术细节

### 侧边栏状态管理重构

**旧实现（checkbox 控制）**:
```html
<!-- 使用 checkbox + label 控制 -->
<input type="checkbox" id="sidebar-toggle" class="sidebar-toggle" />
<label for="sidebar-toggle" class="toggle-sidebar mobile-only">
  <i class="ri-menu-line ri-lg"></i>
</label>
```

**新实现（Vue 响应式）**:
```vue
<script setup lang="ts">
const mobileSidebarVisible = ref(false);

const openMobileSidebar = () => {
  mobileSidebarVisible.value = true;
};

const closeMobileSidebar = () => {
  mobileSidebarVisible.value = false;
};

// 路由变化时自动关闭
watch(
  () => route.fullPath,
  () => {
    closeMobileSidebar();
  }
);
</script>

<template>
  <button type="button" class="toggle-sidebar mobile-only" @click="handleOpenMobileSidebar">
    <i class="ri-menu-line ri-lg"></i>
  </button>
</template>
```

### 邮件格式处理优化

```go
// 检测邮箱是否已包含 <> 格式
if strings.Contains(fromEmail, "<") && strings.Contains(fromEmail, ">") {
    msg.SetHeader("From", fromEmail)
} else {
    msg.SetHeader("From", msg.FormatAddress(fromEmail, fromName))
}
```
