# JeriBlog v3.2.2 版本更新日志

**发布日期**: 2026-06-08  
**提交数量**: 3 个核心提交  
**版本类型**: 功能与修复版本（Feature & Bug Fix Release）

---

## 📋 版本概述

v3.2.2 版本聚焦第三方服务地址配置化与部署体验优化。系统设置新增 Meting-API、头像服务、IP 归属地查询、封面制作 API 和 OAuth Worker 代理配置，前后台相关功能统一读取数据库配置；同时修复全局横向溢出样式，并优化 Dockerfile 的 Alpine 镜像源配置方式。

---

## ✨ 新增特性

### 第三方服务地址配置化
- 新增 `blog.meting_api` 配置，文章编辑器、动态音乐解析和前台音乐播放器统一使用可配置的 Meting-API 地址。
- 新增 `blog.cravatar_url` 配置，前后台头像服务支持通过系统设置切换。
- 新增 `blog.ip_api_url` 配置，访问统计和评论 IP 归属地查询支持自定义查询服务。
- 新增 `blog.cover_maker_api` 配置，后台封面制作图片源 API 支持从系统设置读取。
- 新增 `oauth.worker_proxy` 配置，OAuth Worker 代理地址支持后台配置与热加载。

---

## 🐛 Bug 修复

### 全局横向溢出修复
- 将前台全局 `overflow-x` 从 `hidden` 调整为 `clip`，减少移动端和复杂布局下的横向滚动副作用。

---

## 🚀 性能优化

- 移除前后台音乐解析对后端中转接口的依赖，减少一次服务端代理转发。
- Dockerfile 支持通过 `ALPINE_MIRROR` 构建参数指定 Alpine 镜像源，提升不同网络环境下的镜像构建稳定性。

---

## 🔧 重构优化

- 移除后端 `parse-music` 工具接口及对应 Swagger 文档，音乐解析改为直接使用配置化 Meting-API。
- 头像服务、IP 查询服务和 OAuth Worker 代理增加运行时配置热加载能力。
- 后台设置页新增“第三方服务”和 OAuth 代理配置入口，统一管理外部服务地址。
- 前台 Toast 组件恢复显式 props 传参，模板结构更清晰。

---

## 📚 文档更新

- 更新 README Docker 本地构建示例，补充 `ALPINE_MIRROR` 构建参数。
- 新增 `verchanglog/v3.2.2.md` 版本日志。
- 更新 `README.md` 版本历史。

### Docker 部署
```bash

```

本地构建镜像时可指定 Alpine 镜像源与版本：

```bash
docker build \
  -f deploy/Dockerfile \
  -t jeriblog:3.2.2 \
  --build-arg ALPINE_MIRROR=mirrors.aliyun.com \
  --build-arg APP_VERSION=v3.2.2 \
  .
```
