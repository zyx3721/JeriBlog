## 📋 版本概述

v3.0.1 是 JeriBlog 的补丁版本，主要修复了在阿里云 ESA (Edge Security Acceleration) 环境下获取真实客户端 IP 地址的问题。通过优化 IP 获取逻辑，确保在 CDN、反向代理等复杂网络环境下能够正确识别客户端真实 IP，提升了日志记录、限流控制、统计分析等功能的准确性。

---

## ✨ 新增特性

### IP 地址获取优化
- 新增 `GetRealIP` 工具函数，统一处理客户端 IP 获取逻辑
- 支持阿里云 ESA 专用头部 (`Ali-CDN-Real-IP`, `X-Client-IP`)
- 优化 `X-Forwarded-For` 解析，自动过滤内网 IP
- 建立 IP 获取优先级机制：阿里云 ESA > X-Forwarded-For > X-Real-IP > ClientIP

---

## 🐛 Bug 修复

### 阿里云 ESA 环境 IP 获取修复
- **问题描述**: 在阿里云 ESA 环境下，使用 `c.ClientIP()` 获取的是 CDN 节点 IP 而非真实客户端 IP
- **影响范围**: 
  - 日志记录中的客户端 IP 不准确
  - 基于 IP 的限流控制失效
  - 评论、反馈的 IP 记录错误
  - 统计数据中的访问来源不准确
- **修复方案**: 
  - 在 `server/pkg/utils/ip.go` 中实现 `GetRealIP` 函数
  - 优先读取阿里云 ESA 的 `Ali-CDN-Real-IP` 和 `X-Client-IP` 头部
  - 智能解析 `X-Forwarded-For`，过滤内网和回环地址
  - 在所有需要获取客户端 IP 的地方替换为 `utils.GetRealIP(c)`

### 涉及文件修复

```nginx
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
}
```

## 🔍 技术细节

### GetRealIP 函数实现逻辑

```go
func GetRealIP(c *gin.Context) string {
    // 1. 优先使用阿里云 ESA 的真实 IP 头部
    if ip := c.GetHeader("Ali-CDN-Real-IP"); ip != "" {
        return ip
    }
    if ip := c.GetHeader("X-Client-IP"); ip != "" {
        return ip
    }

    // 2. 使用 X-Forwarded-For (取第一个非内网 IP)
    if xff := c.GetHeader("X-Forwarded-For"); xff != "" {
        ips := strings.Split(xff, ",")
        for _, ip := range ips {
            ip = strings.TrimSpace(ip)
            if parsedIP := net.ParseIP(ip); parsedIP != nil {
                if !parsedIP.IsLoopback() && !parsedIP.IsPrivate() {
                    return ip
                }
            }
        }
    }

    // 3. 使用 X-Real-IP
    if ip := c.GetHeader("X-Real-IP"); ip != "" {
        return ip
    }

    // 4. 最后使用 Gin 的默认方法
    return c.ClientIP()
}
```

### IP 获取优先级说明

| 优先级 | 头部名称 | 说明 | 适用场景 |
|:---:|:---:|:---:|:---:|
| 1 | `Ali-CDN-Real-IP` | 阿里云 ESA 专用头部 | 阿里云 ESA 环境 |
| 2 | `X-Client-IP` | 阿里云 ESA 备用头部 | 阿里云 ESA 环境 |
| 3 | `X-Forwarded-For` | 标准代理头部（取第一个非内网 IP） | 多层代理环境 |
| 4 | `X-Real-IP` | Nginx 常用头部 | Nginx 反向代理 |
| 5 | `ClientIP()` | Gin 默认方法 | 直连或其他环境 |
