---

## 📋 版本概述

v3.1.1 版本围绕前台阅读体验与文章导入稳定性展开，新增随机阅读入口和随机文章公开接口，同时修复导入文章时自定义 GitHub 图片代理被默认代理二次拼接的问题。

---

## ✨ 新增特性

### 随机阅读功能
- 前台导航栏新增随机阅读按钮，点击后跳转到随机文章详情页。
- 新增 `GET /api/v1/articles/random` 公开接口，随机返回一篇已发布文章的 `slug`。
- 前端随机阅读按钮增加加载状态，避免重复触发跳转。

---

## 🐛 Bug 修复

### 自定义图片代理二次拼接
- 移除 `fetchImage` 中的默认代理拼接逻辑，使其只负责下载传入的最终 URL。
- 将 GitHub raw 图片代理决策统一放到 `uploadSingleImage`。
- 自定义代理优先生效，留空时回落到 `https://gh.llkk.cc/`。

---

## 🚀 性能优化

- 随机文章接口仅查询已发布文章的 `slug` 字段，避免加载完整文章内容。
- 随机阅读按钮通过加载状态限制重复请求，减少无效接口调用。

---

## 🔧 重构优化

- 新增 `resolveImageDownloadURL` 和 `isGitHubRawURL` 辅助逻辑，集中处理 GitHub raw 图片代理策略。
- `fetchImage` 职责收敛为纯 HTTP 下载，减少隐式副作用。
- 随机文章按 Controller / Service / Repository 分层接入，保持现有架构风格。

---
