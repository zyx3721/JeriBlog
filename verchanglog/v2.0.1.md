# JeriBlog v2.0.1 版本更新日志

**发布日期**: 2026-04-27  
**提交数量**: 11 次提交

## 📋 版本概述

JeriBlog v2.0.1 是一个功能增强与优化版本，主要围绕 **文章管理系统**、**文件上传功能**、**Nginx 性能优化** 进行了全面改进。新增了文章筛选功能、多媒体文件类型识别、GitHub 图片代理加速、Gzip 压缩优化等核心功能，并完成了移动端响应式布局优化和 Markdown 渲染问题修复，显著提升了系统的易用性和性能。

---

## ✨ 新增特性

### 文章管理系统增强

- **文章筛选功能**
  - 新增文章筛选面板组件（FilterPanel.vue）
  - 新增文章筛选器组件（ArticleFilter.vue）
  - 支持按分类筛选文章
  - 支持按标签筛选文章
  - 支持按发布状态筛选（已发布、草稿）
  - 支持按时间范围筛选（创建时间、更新时间）
  - 修复移动端时间筛选逻辑问题
  - 优化筛选面板移动端布局

- **文章导出功能优化**
  - 文章导出时对 GitHub 图片使用代理加速下载
  - 优化图片下载速度和稳定性
  - 支持自动识别 GitHub 图片链接并应用代理

- **文章管理布局优化**
  - 优化文章管理页面整体布局
  - 优化文章列表移动端显示效果
  - 优化文章编辑器移动端体验
  - 修复文章管理编辑器功能问题

### 多媒体文件支持增强

- **文件类型识别优化**
  - 支持文章多媒体文件类型识别
  - 新增音频文件类型识别（MP3、WAV、FLAC、AAC、OGG、M4A、WMA）
  - 新增视频文件类型识别（MP4、AVI、MKV、MOV、WMV、FLV、WEBM）
  - 新增图片文件类型识别（JPG、JPEG、PNG、GIF、BMP、WEBP、SVG、ICO）
  - 新增文档文件类型识别（PDF、DOC、DOCX、XLS、XLSX、PPT、PPTX、TXT、MD）

- **音频播放优化**
  - 优化音频文件播放功能
  - 支持多种音频格式播放
  - 优化音频播放器样式

### 文件上传功能优化

- **超时设置统一优化**
  - 统一优化所有文件上传功能的超时设置
  - 前端请求超时时间调整为 5 分钟（300000ms）
  - 后端文件上传超时时间调整为 5 分钟
  - 解决大文件上传超时问题

### Nginx 性能优化

- **Gzip 压缩优化**
  - 生产环境 Nginx 配置新增 Gzip 压缩
  - 压缩级别设置为 6（平衡压缩率和 CPU 消耗）
  - 压缩类型包含：text/plain、text/css、text/javascript、application/json、application/javascript、application/xml、image/svg+xml
  - 最小压缩文件大小设置为 1KB
  - 优化传输性能，减少带宽消耗

### 移动端响应式优化

- **文章管理移动端优化**
  - 优化文章管理移动端体验
  - 优化文章筛选功能移动端布局
  - 优化文章列表移动端显示
  - 优化文章编辑器移动端操作

- **管理端样式优化**
  - 优化管理端整体样式
  - 优化按钮布局和间距
  - 优化表单布局和对齐
