## 📋 版本概述

v3.0.0 是 JeriBlog 的重大版本更新，进行了全面的架构重构和代码优化。本版本重点优化了前后端代码结构，新增 MCP 协议支持，增强了动态音频功能，改进了邮件服务配置，并对管理后台进行了全面的布局重构。同时移除了微信公众号 API 依赖，优化了 AI 函数调用机制，提升了系统的整体性能和可维护性。

---

## ✨ 新增特性

### MCP 协议支持
- 新增完整的 MCP (Model Context Protocol) 服务端实现
- 提供 9 大类管理工具：
  - 文章管理 (article_manage)
  - 评论管理 (comment_manage)
  - 友链管理 (friend_manage)
  - 动态管理 (moment_manage)
  - RSS 订阅管理 (rssfeed_manage)
  - 统计查询 (stats_query)
  - 分类/标签管理 (taxonomy_manage)
  - 用户管理 (user_manage)
  - 访问日志管理 (visit_manage)
- 支持 SSE (Server-Sent Events) 长连接通信
- 新增 MCP 密钥配置项 (ai.mcp_secret)
- Nginx 配置新增 /mcp 路由支持

### 动态音频功能
- 前台动态页面新增音频播放器
- 管理后台支持动态音频上传与管理
- 音频文件引用详情展示优化
- 支持音频文件的完整生命周期管理

### 邮件服务增强
- 支持多种加密方式 (SSL/TLS/STARTTLS)
- 新增独立发件人邮箱配置 (notification.email_from)
- 新增邮件加密方式配置 (notification.email_secure)
- 优化邮件模板样式 (评论通知、反馈通知、友链申请)

### 页面配置增强
- 新增首页布局配置 (blog.home_layout)
- 新增动态页面大小配置 (blog.moments_size)
- 新增留言页面内容配置 (blog.message_content)
- 新增页脚右侧链接配置 (blog.footer_links)

### 用户安全增强
- 新增 Token 版本控制机制 (token_version)
- 支持一键撤销所有用户 Token
- 优化 JWT 认证流程
- 新增 Cookie 认证支持

## 🔄 升级说明

### 数据库迁移

**自动迁移**（推荐）：
```bash
# 启动应用时会自动执行迁移
./jeriblog
```

**手动迁移**：
```sql
-- 1. 添加 Token 版本控制字段
ALTER TABLE users ADD COLUMN IF NOT EXISTS token_version INT DEFAULT 0 NOT NULL;

-- 2. 添加邮件配置项
INSERT INTO settings (key, value, "group", is_public) VALUES
('notification.email_secure', 'ssl', 'notification', FALSE),
('notification.email_from', '', 'notification', FALSE)
ON CONFLICT (key) DO NOTHING;

-- 3. 添加 MCP 密钥配置
INSERT INTO settings (key, value, "group", is_public, created_at, updated_at)
VALUES ('ai.mcp_secret', '', 'ai', FALSE, CURRENT_TIMESTAMP, CURRENT_TIMESTAMP)
ON CONFLICT (key) DO UPDATE SET updated_at = CURRENT_TIMESTAMP;

-- 4. 添加页脚链接配置
INSERT INTO settings (key, value, "group", is_public, created_at, updated_at)
VALUES ('blog.footer_links', '[{"name":"订阅","url":"/subscribe"},{"name":"源码","url":"https://github.com/zyx3721/JeriBlog"}]', 'blog', TRUE, CURRENT_TIMESTAMP, CURRENT_TIMESTAMP)
ON CONFLICT (key) DO UPDATE SET updated_at = CURRENT_TIMESTAMP;

-- 5. 移除微信公众号配置
DELETE FROM settings WHERE "group" = 'wechat';

-- 6. 添加页面配置项
INSERT INTO settings (key, value, "group", is_public, created_at, updated_at)
VALUES 
('blog.moments_size', '30', 'blog', TRUE, CURRENT_TIMESTAMP, CURRENT_TIMESTAMP),
('blog.message_content', '时光流逝，岁月如歌。
```

### Nginx 配置更新

在 Nginx 配置中新增 MCP 路由：

```nginx
# MCP 工具
location = /mcp {
    proxy_pass http://127.0.0.1:8080/mcp;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_connect_timeout 600s;
    proxy_send_timeout 600s;
    proxy_read_timeout 600s;
}
```

### 环境变量配置

无需新增环境变量，所有配置项均通过数据库管理。

### 注意事项

1. **Token 失效**：升级后所有用户的 Token 将保持有效，但管理员可通过后台一键撤销所有 Token
2. **微信公众号功能**：微信公众号功能已调整为仅本地渲染，不再需要 API 凭证
3. **邮件配置**：升级后需在后台重新配置邮件加密方式和发件人邮箱
4. **MCP 功能**：如需使用 MCP 功能，需在后台配置 MCP 密钥
5. **前端缓存**：建议清除浏览器缓存以获取最新的前端资源
