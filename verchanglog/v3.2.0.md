# JeriBlog v3.2.0 版本更新日志

**发布日期**: 2026-05-29  
**提交数量**: 8 个核心提交  
**版本类型**: 功能与修复版本（Feature and Bug Fix Release）

---

## 📋 版本概述

v3.2.0 版本围绕订阅能力、开发部署配置和管理端移动体验进行增强。新增公众号订阅配置并完善前台 RSS 订阅页，支持后端监听地址配置，优化管理端运行时配置和 Docker 镜像版本注入，同时修复文件选择器分页、移动端表单布局、开发环境复制 RSS 链接等问题。

---

## ✨ 新增特性

### 公众号订阅与 RSS 订阅增强
- 新增公众号二维码配置项，支持在博客配置中维护公众号订阅信息。
- 前台 RSS 订阅页补充公众号订阅展示能力，方便读者通过多渠道订阅内容。
- 文件引用识别补充公众号二维码类型，方便在文件管理中查看配置引用关系。

### 后端监听地址配置
- 新增 `SERVER_HOST` 环境变量，默认监听 `localhost`。
- 开发或容器环境可配置 `SERVER_HOST=0.0.0.0`，方便局域网和容器网络访问后端服务。

### Docker 镜像版本注入
- Docker 构建支持通过 `APP_VERSION` 注入后端系统版本号。
- 系统信息中的当前版本不再只依赖 Go 默认值，正式镜像可显示构建时传入的版本。

---

## 🐛 Bug 修复

### 文件选择器分页修复
- 修复全局文件选择器选择 `200条/页` 或 `全部` 时因后端分页上限校验导致的“入参错误”。
- “全部”选项会先获取当前总数，再按实际总数请求，避免固定上限带来的数据缺失。

### 管理端运行时配置修复
- 优化 `admin/public/config.js` 为本地开发占位配置，避免覆盖 `.env` 中的 `VITE_API_URL`。
- 修复开发环境访问管理后台时仍使用 `localhost:8080` 的问题。
- 避免本地 Vite 开发环境出现 `config.js` 返回 HTML 导致的语法错误。

### RSS 链接复制兼容
- 前台 RSS 订阅页复制链接在 HTTP 开发环境下增加降级复制逻辑。
- 修复非安全上下文中 `navigator.clipboard` 不可用导致的复制失败。

### 管理端移动端表单布局修复
- 优化博客配置中侧边栏社交、页脚社交、页脚链接、个人资料、联系方式、创作平台、站长联盟和版本信息等配置项的移动端分行布局。
- 修复部分字段过窄、图标按钮高度异常、上下按钮间距不一致等显示问题。
- 修复博客配置中公众号名称输入框未与标签对齐的问题。

### Admin 构建修复
- 修复博客配置组件中移动端布局参数导致的管理端构建失败问题。

---

## 🚀 性能优化

- 文件选择器“全部”模式按实际总数动态请求，避免使用无意义的超大分页参数。
- 移动端配置表单使用更稳定的网格布局，减少字段换行和按钮区域导致的布局抖动。

---

## 🔧 重构优化

- `JsonListEditor` 增加移动端布局模式，复用同一个组件支持多种配置项排版。
- 管理端运行时配置职责更清晰：开发环境优先使用 `.env`，Docker 生产环境由启动脚本生成运行时配置。
- 后端服务监听地址从固定 `localhost` 调整为配置驱动。
- Docker 构建参数同时服务前台版本展示和后端系统版本展示。

## 🔄 升级说明

### 兼容性
- ✅ 向后兼容，无破坏性变更
- ✅ 数据库迁移随服务启动流程自动执行
- ✅ Docker 部署建议显式传入 `APP_VERSION`

### 环境变量
```bash
# 后端监听地址，容器或局域网访问可设置为 0.0.0.0
SERVER_HOST=0.0.0.0
```

### Docker 部署
```bash
docker pull zyx3721/jeriblog:3.2.0
```

本地构建镜像时可指定版本：

```bash
docker build -f deploy/Dockerfile -t jeriblog:3.2.0 --build-arg APP_VERSION=v3.2.0 .
```
